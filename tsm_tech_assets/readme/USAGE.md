1. As a TSM manager, open the technical asset types in TSM configuration. Add or
   edit each type's name directly in the list.
2. Open **TSM > Tech Assets** and create an asset with a title, customer, type and
   responsible user. Add technical and configuration notes and choose its privacy.
3. In a task, use **Add** in the technical assets field to select related assets.
   The selection is filtered by the task customer's hierarchy.
4. Click an asset card to open its form in a dialog. Use the diagonal triangle to
   open the full form, or the red cross to remove the link from the task. Removing
   this link does not delete the asset.
5. From an asset, use the tasks button to consult its related tasks, including
   archived tasks allowed by your access rights. Use the email button or print
   actions to share its details or reports.

TSM users can read asset types; TSM managers maintain them. Asset visibility and
operations follow the module's existing privacy and follower rules.
