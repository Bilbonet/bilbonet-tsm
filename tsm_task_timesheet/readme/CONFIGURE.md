In TSM > Configuration > Settings, select Timesheet Title for free-text
descriptions or Timesheet Tag for classification. Selecting either option in
the settings form clears the other.

Leave both options disabled to record time without entering titles or tags.

With Timesheet Tag enabled, manage tags in Configuration > Timesheet Tags
(system access is required for this menu). Only one active tag can be marked
as the default. The addon provides an initial "-- Undefined --" tag.
