- TSM users can record and track time spent on support tasks.
- Stop computes elapsed time from the start datetime. Durations are stored
  in decimal hours and displayed as hours and minutes.
- Users can open and close tasks from their timesheet lines. Closing selects
  the first stage found with "Closed" checked and requires nonzero durations
  on all timesheets of the task.
- List, kanban, calendar and pivot views support time analysis by task,
  project and user. This addon uses TSM timesheets, not analytic lines.
