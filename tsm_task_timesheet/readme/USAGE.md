To use this module:

1. Open TSM and create or open a task. Add a line in its Timesheets tab,
   or open Timesheet > My Timesheets and select a task.
   In the standalone list or form, you can select a project first to filter
   the available tasks, or select a task first to fill its project and customer.
   While a task is selected, only its project is offered. Clear the task before
   choosing another project. Enable the optional Project column to use it in lists.
2. Enter a start datetime and duration, or click Stop to calculate elapsed
   time. Stop requires a start datetime.
3. Enter a task title and customer in Kanban quick creation, then click Start.
   Missing required fields are highlighted and must be completed before saving.
   Start saves the task, adds a running timesheet and opens the task for editing.
   This also replaces the task description with a timestamp.
4. Use Open task or Close task from a timesheet to change the task stage.
   Closing requires all timesheets of that task to have nonzero durations.

Managers also have All Timesheets and Reporting menus. My Timesheets is a
navigation filter; it does not establish per-user access restrictions.
