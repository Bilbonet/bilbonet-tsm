Configure each agent contact with its **TSM Commission** in the agent information
page. Use a commission with settlement type **Timesheet**, an hourly product and
the required percentage or sections. The general **Commission** remains the
separate default used by sales and invoice commissions.

Select **Task Based** to settle at any task stage, or **Task Closed** to wait for
a closed stage. Set the agent's settlement period as usual in OCA commissions.
Access to commission setup and settlement actions follows the OCA commission
groups; TSM membership alone does not grant access to those actions.
