# Decisiones arquitectónicas

Guarda aquí las decisiones arquitectónicas relevantes para el módulo. Crea cada decisión
copiando ../templates/decision.md.

Utiliza esta carpeta cuando haya que documentar una elección con consecuencias a largo
plazo, impacto transversal, implicaciones de migración o efectos de compatibilidad.

No crees una decisión por cada change spec ni por elecciones rutinarias que siguen un
patrón establecido. Registra una decisión cuando su justificación y consecuencias
merezcan conservarse más allá del cambio actual; omite los apartados que no sean
pertinentes.

Una decisión debe explicar:

- el contexto;
- el problema;
- la opción elegida;
- las alternativas consideradas;
- las consecuencias;
- el impacto de migración o compatibilidad;
- los puntos que sigan abiertos.

Las decisiones arquitectónicas explican por qué se ha elegido una solución, pero no
sustituyen los requisitos funcionales ni los criterios de aceptación de una change spec.
