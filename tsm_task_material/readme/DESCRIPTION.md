Record the products and services used on Technical Support Management tasks and
generate a sales quotation or confirmed order from the recorded lines.

The module extends `tsm_base` with:

- A *Material* tab with descriptions, quantities, units of measure, unit prices,
  discounts, subtotals and a total amount.
- Sales creation from selected task stages, with optional automatic confirmation.
- A link from each task to its sales document, displaying the untaxed order
  amount in the task company's currency.
- Material details and totals in task and project reports.
- Access to material lines based on the task's company, privacy and assignment,
  with editing blocked once a sales document is linked.
